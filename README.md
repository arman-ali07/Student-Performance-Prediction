# Student Performance Prediction

## Project Overview
This project aims to analyze student performance data and build machine learning models to predict students' academic performance based on various factors such as study time, attendance, parental support, extracurricular activities, and GPA.

## Dataset
- Dataset: Student Performance Dataset
- Total Records: 2,392
- Total Features: 15
